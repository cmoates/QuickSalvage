# Contributing

Thank you for helping improve QuickSalvage.

## Before you start

- Test changes in-game with UE4SS Lua reload (Ctrl+R) after joining a world.
- Keep pull requests focused on one behavior or fix.
- Match the simple style in `Scripts/main.lua` (readable hooks, minimal abstraction).

## Pull requests

1. Fork the repository and create a branch from `main`.
2. Describe what changed and why in the PR summary.
3. Note your Palworld / UE4SS versions if relevant.

## Reporting issues

Include when possible:

- UE4SS version
- Single-player vs dedicated-server client
- Relevant lines from `UE4SS.log` (especially `[QuickSalvage]` messages)
- Whether the mod was toggled with Alt+F9
